El resultado

De una idea de clase a un juego que puedes compartir.

Construye un prototipo de videojuego retro —por ejemplo, un arcade inspirado en Galaxian— para practicar phrasal verbs, vocabulario o gramática en contexto.

Al terminar, podrás Probar tu juego en el navegador y publicarlo gratis con GitHub Pages para usarlo en clase.
Ruta del taller

Cuatro módulos, un proyecto real.

Una sesión guiada que combina configuración, diseño pedagógico, creación con IA y publicación.

MÓDULO 01

Prepara tu entorno digital

Crea una cuenta y un repositorio en GitHub, recorre Visual Studio Code y conoce la estructura básica de una página y un videojuego 2D.

MÓDULO 02

Diseña prompts para juegos

Aprende a pedirle a un asistente de IA la lógica del juego y convierte los objetivos del inglés en reglas e interacciones.

MÓDULO 03

Construye un prototipo arcade

Crea un juego retro estilo Galaxian: el jugador identifica la respuesta correcta para el significado o complemento de un phrasal verb.

MÓDULO 04

Personaliza y publica

Adapta el proyecto a tu currículo, resuelve errores con acompañamiento y publícalo gratis en GitHub Pages.

Antes de empezar

¿Qué necesitas?

Para participar

  • Un computador portátil personal.
  • Acceso estable a Internet.
  • Un navegador actualizado, como Chrome o Edge.

No necesitas saber programar

  • El taller es para principiantes y parte desde cero.
  • Se trabajará con GitHub, Visual Studio Code y asistentes de IA, como Codex o Cursor.
  • Debes poder crear cuentas gratuitas en las herramientas utilizadas.
