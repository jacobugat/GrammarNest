# English Gamification · Adjective Arcade

An educational Pac-Man adaptation for practicing adjective translations, comparatives, and superlatives.

## Jugar

Open `index.html` in a browser. Choose A1, A2, B1, or a mix of levels, then play a round of 50, 100, or 150 adjectives. Words are selected at random without repeats within a round. The bank contains 500 entries.

Controls: arrow keys or WASD to move, Esc to pause, and Q to toggle sound.

## Desarrollo

Con Node.js instalado, ejecuta `npm install`, `npm run watch` y `npm run serve` para compilar los archivos fuente y servir el juego localmente.

Las fuentes y notas del banco de palabras están en [`app/data/README.md`](app/data/README.md). Se conserva la licencia del proyecto original en [`LICENSE`](LICENSE).
