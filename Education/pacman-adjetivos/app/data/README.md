# Banco de adjetivos

El juego incluye 500 adjetivos etiquetados como A1, A2 o B1. Las etiquetas de nivel se basan en el **CEFR-J Vocabulary Profile 1.5**, compilado por Yukio Tono, Tokyo University of Foreign Studies, y distribuido por [Open Language Profiles](https://github.com/openlanguageprofiles/olp-en-cefrj). Sus términos de uso permiten usos de investigación y comerciales sin costo cuando se cita el conjunto de datos.

Las traducciones españolas se apoyan en el diccionario [Spanish–English JSON](https://github.com/fufu70/spanish-english-json), con correcciones editoriales para las palabras más frecuentes. Las formas comparativas y superlativas se generaron para el juego y se ajustaron manualmente en las formas irregulares comunes.

Las categorías A1, A2 y B1 orientan la práctica; pueden variar entre currículos y fuentes.
